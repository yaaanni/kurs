# Что нужно сделать

Прогнать тест производительности процессора на своём ноутбуке и прислать мне
один файл. Занимает минут пять, из них минуту — сами измерения.

Это для курсовой по АВС: сравниваем два процессора на вычислении чисел
Фибоначчи. Нужен **Linux x86-64**. Программа уже собрана, компилировать
ничего не надо.

## Перед запуском

1. Воткни ноутбук в розетку — от батареи процессор режет частоту.
2. Закрой IDE, браузер, Telegram и всё остальное. Посторонняя нагрузка
   портит замеры.
3. Дай ноутбуку остыть, если до этого что-то тяжёлое гонял.

## Запуск

Ты уже в папке с проектом — там, где лежат `run_on_amd.sh` и `Makefile`.
Никаких архивов распаковывать не надо, ничего никуда переходить тоже.

```bash
chmod +x run_on_amd.sh scripts/run_bench.sh fibbench
./run_on_amd.sh
```

Первая команда нужна, если проект скачан ZIP-ом: при распаковке теряется
признак «файл можно запускать». Если клонировал через `git clone` — она
просто ничего не изменит, вреда от неё нет.

Скрипт сам всё проверит и будет задавать вопросы — на все можно отвечать
Enter. Один раз попросит пароль администратора: это нужно, чтобы включить
режим `performance` (иначе процессор будет сбрасывать частоту и замеры
получатся мусорные). После прогона прежний режим возвращается обратно.

Если у тебя **не** AMD Ryzen 7 7840HS, скрипт предупредит и спросит,
продолжать ли — отвечай «д», только напиши мне потом модель процессора.

## Что прислать

В конце скрипт сам соберёт архив и напишет его имя:

```
fibbench-amd-results.tar.gz
```

Вот его и пришли. Внутри — результаты замеров, протокол прогона и, если у
тебя GNOME, скриншоты. Ничего личного туда не попадает: только модель
процессора, версия системы и цифры.

## Если что-то пошло не так

**`bash: ./run_on_amd.sh: Permission denied`** — не выполнил `chmod` выше.
Либо запусти так, это работает всегда:
```bash
bash run_on_amd.sh
```

**`cd: fibbench: Это не каталог`** — никуда переходить не надо, `fibbench`
это файл программы. Запускай из той папки, где стоишь.

**`tar: fibbench-amd.tar.gz: Нет такого файла`** — архива в репозитории нет
и не нужно, это из старой инструкции. Сразу запускай `./run_on_amd.sh`.

**Не запускается `fibbench`** — скрипт предложит пересобрать из исходников,
соглашайся. Если скажет, что нет компилятора:
```bash
sudo apt install build-essential     # Debian/Ubuntu
sudo dnf install gcc make            # Fedora
sudo pacman -S base-devel            # Arch
```

**Нет `pkexec` и `sudo`** — не страшно, скрипт отработает без прав
администратора, просто напиши мне, что режим `performance` включить не вышло.

**Скриншоты не снялись** — тоже не страшно, я сниму свои. Если не сложно,
сделай вручную снимок вывода команды `lscpu`.

**Вообще ничего не работает** — пришли, что вывелось в терминале, разберёмся.
