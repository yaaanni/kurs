# fibbench — программа сравнения производительности процессоров

Курсовой проект по дисциплине «Архитектура вычислительных систем».
Сравнение Intel Core i7-8565U и AMD Ryzen 7 7840HS на вычислении чисел Фибоначчи.

## Состав

    src/            исходный код на языке C (стандарт C11)
      fib.c/.h        четыре метода вычисления чисел Фибоначчи
      timer.c/.h      монотонный таймер CLOCK_MONOTONIC_RAW
      stats.c/.h      медиана, минимум, среднее, СКО
      sysinfo.c/.h    сведения о системе, привязка к ядрам
      report.c/.h     вывод на консоль и экспорт в CSV
      main.c          разбор параметров, управление экспериментом
    scripts/
      run_bench.sh      прогон с фиксацией условий эксперимента
      make_plots.py     построение графиков из CSV
      shoot.py          копии экрана (окно gnome-terminal + портал снимков)
      pack_for_amd.sh   комплект для второй вычислительной системы
      run_on_amd.sh     прогон на второй системе (запускается там)
      unpack_amd.sh     приём результатов со второй системы
      build_chapters.py формирование разделов 3–5 пояснительной записки
      docxkit.py        оформление по СТП 01-2024
      chapter3/4/5.py   содержание разделов
    results/        протоколы прогонов (.log) и результаты (.csv)
    figures/        графики и копии экрана
    base_zapiska.docx  эталон записки: разделы 1–2 готовы, 3–5 пустые

## Методы вычисления

| № | Метод | Нагружаемый узел процессора |
|---|-------|------------------------------|
| 1 | Наивная рекурсия, O(2^n) | стек вызовов, предсказатель переходов, конвейер |
| 2 | Итерационный, O(n) | арифметико-логическое устройство |
| 3 | Длинная арифметика | подсистема кэш-памяти |
| 4 | Многопоточный режим | вычислительные ядра, подсистема питания |

## Сборка и запуск

    make
    ./scripts/run_bench.sh intel              # обычный прогон
    pkexec $PWD/scripts/run_bench.sh intel    # в режиме performance (запросит пароль)

Перед прогоном закройте среду разработки и браузер: посторонняя нагрузка
искажает результат даже при привязке процесса к отдельному ядру, так как
соседний логический поток того же ядра делит с ним исполнительные устройства.
Скрипт предупреждает, если средняя загрузка системы превышает 0,6.

## Прогон на второй вычислительной системе (AMD Ryzen 7 7840HS)

Исполняемый файл скомпонован статически и НЕ пересобирается на второй
системе: сравнение требует, чтобы на обеих машинах выполнялся один и тот же
машинный код. Версия glibc и дистрибутив на второй машине значения не имеют.

На первой машине:

    ./scripts/pack_for_amd.sh                       # -> fibbench-amd.tar.gz
    scp fibbench-amd.tar.gz пользователь@адрес:~/

На второй машине (любой Linux x86-64):

    tar -xzf fibbench-amd.tar.gz
    cd fibbench
    ./run_on_amd.sh

Скрипт проверит систему и контрольную сумму исполняемого файла, предупредит
о посторонней нагрузке и о работе от батареи, запросит права администратора
для режима performance, проведёт измерения, при наличии графической среды
снимет копии экрана и соберёт fibbench-amd-results.tar.gz.

Обратно на первой машине:

    scp пользователь@адрес:~/fibbench/fibbench-amd-results.tar.gz .
    ./scripts/unpack_amd.sh fibbench-amd-results.tar.gz

Последняя команда сама построит графики и пересоберёт разделы 3-5 записки.

## Обработка результатов

    python3 scripts/make_plots.py       # графики -> figures/
    python3 scripts/shoot.py intel      # копии экрана -> figures/
    python3 scripts/build_chapters.py   # разделы 3–5 записки

build_chapters.py всегда формирует разделы заново из base_zapiska.docx,
поэтому его можно запускать сколько угодно раз.
